## Getting Started

To make use of this open source project:
1. Clone the repo on this link using VSCode editor: https://github.com/AmaduKamara/WEB_DESIGN_FINAL_PROJECT_LENOSOL_FOODS_BIT1102.git
2. Open the Cloned project with this command: `cd WEB_DESIGN_FINAL_PROJECT_LENOSOL_FOODS_BIT1102`
3. Launch the project through the index.html file
